## M2A 심화코칭 리포트 고정 블록 대장

보험설계사 성향별 심화코칭 리포트 5종을 섹션·블록 단위로 기계 대조해, 시스템(자동 생성) 구축 시 각 블록을 어떻게 다룰지 판정한 재료 대장이다.

- **[고정]** = 5명 전부 동일(이름·호칭만 치환). 문자열 그대로 재료가 됨.
- **[규칙]** = 점수에 따라 선택·삽입. 규칙만 있으면 산문 생성 없이 조립 가능.
- **[생성]** = 서술이 그때그때 달라져 단순 치환 불가. LLM 생성 슬롯.

> 전역 치환 슬롯 2개: `{이름}` (김정임·허진랑…), `{호칭}` = PA님 / TCR님 (지침 첫 페이지에서 확정. 허진랑만 TCR님, 나머지 4명 PA님). 아래 [고정] 문자열의 `{호칭}`은 전부 이 슬롯이다.

## 2. [고정] 블록 전문 (복붙 재료)

### 2-1. ① 리포트의 목적 (블록 #1)

```
이 리포트는 {이름} {호칭}의 에고성향을 바탕으로 고객의 성향을 빠르게 파악하고, 고객의 성향에 맞는 상담 방법과 고객관리, 거절 대응, 소개 전략까지 실제 보험영업 현장에서 바로 활용할 수 있도록 제작된 M2A 성향별 심화코칭 리포트입니다.

보험은 같은 상품을 설명해도 고객마다 중요하게 생각하는 기준이 다릅니다. 고객의 성향을 이해하면 상담은 자연스러워지고 고객이 원하는 방식으로 설명할 수 있으며, 계약 이후에도 오래 신뢰받는 관계를 만들 수 있습니다.

보험은 상품을 판매하는 일이 아니라 고객의 미래를 준비하는 일입니다. 다섯 가지 에고성향을 상황에 맞게 활용할수록 고객은 신뢰를 느끼고, 그 신뢰는 계약을 넘어 소개와 장기적인 고객관계로 이어집니다.
```

### 2-2. ③~⑦ 고객특징 도입부 5종 (블록 #6)

헤더 라인은 두 변형이 존재한다. 표준으로 **변형B**(괄호 성향코드 포함)를 권장한다.
- 변형A: `🔴 기준·결단 성향이 높은 고객을 10분만에 알아보는 방법`
- 변형B: `🔴 기준·결단(CP) 성향 고객을 10분 만에 알아보는 방법`

본문 문단은 완전 고정(`{호칭}`만 치환):

**🔴 CP (기준·결단)**
```
기준·결단 성향이 높은 고객은 상담을 시작하면 {호칭}의 신뢰와 책임감을 먼저 확인합니다. "몇 년 동안 일하셨나요?", "계약 후에도 계속 관리해 주시나요?", "약속은 확실히 지켜주시죠?"처럼 사람을 검증하는 질문을 자주 합니다. 표정은 진지하고 쉽게 웃지 않으며 {호칭}의 말보다 태도와 신뢰감을 유심히 살펴봅니다. 이러한 고객은 상품보다 {호칭}을 먼저 선택하는 성향이 강합니다.
```

**🟠 NP (배려·공감)**
```
배려·공감 성향이 높은 고객은 상담을 시작하면 {호칭}이 나를 얼마나 진심으로 이해하고 배려하는지 먼저 느끼려고 합니다. "고생 많으셨네요.", "친절하게 설명해 주시네요.", "말씀하시니까 마음이 편하네요."처럼 상대를 인정하거나 공감하는 말을 자연스럽게 합니다. 미소를 자주 보이고 고개를 끄덕이며 이야기를 잘 들어주는 모습이 많습니다. 이러한 고객은 상품보다 사람과의 관계를 먼저 중요하게 생각하는 성향이 강합니다.
```

**🔵 A (이성·판단)**
```
이성·판단 성향이 높은 고객은 {호칭}의 신뢰보다 상품의 타당성과 합리성을 먼저 확인합니다. "왜 이 상품이 더 좋은가요?", "보험료 차이는 왜 나는 거죠?", "다른 회사와 비교하면 어떤 장점이 있나요?"처럼 상품과 내용을 분석하는 질문을 자주 합니다. 표정은 차분하고 생각하는 시간이 길며 설명을 들으면서 스스로 비교하고 계산하는 모습을 보입니다. 이러한 고객은 {호칭}보다 상품의 논리와 근거를 먼저 판단하는 성향이 강합니다.
```

**🟢 FC (친화·표현)**
```
친화·표현 성향이 높은 고객은 상담을 시작하면 {호칭}과 편안하게 소통할 수 있는 사람인지 먼저 느끼려고 합니다. "분위기가 좋네요.", "이해하기 쉽게 설명해 주세요.", "편하게 이야기하세요."처럼 밝고 긍정적인 표현을 자주 사용합니다. 잘 웃고 리액션이 크며 자연스럽게 대화를 이어갑니다. 이러한 고객은 상품보다 상담 분위기와 {호칭}에 대한 호감을 먼저 중요하게 생각하는 성향이 강합니다.
```

**🟣 AC (협조·조율)**
```
협조·조율 성향이 높은 고객은 상담을 시작하면 부담을 주는 사람인지, 편안하게 이야기할 수 있는 사람인지 먼저 살펴봅니다. "생각해 볼게요.", "괜찮습니다.", "죄송합니다."처럼 조심스럽게 말하는 경우가 많으며 질문을 많이 하기보다 먼저 듣는 편입니다. 표정은 다소 긴장되어 있고 상대의 반응을 살피는 모습이 자주 나타납니다. 이러한 고객은 {호칭}의 배려와 부담 없는 상담을 가장 중요하게 생각하는 성향이 강합니다.
```

### 2-3. ③~⑦ 상담 화법 고정 풀 (블록 #10, 각 유형 5줄)

> 아래는 저성향 스왑이 없는 표준 버전(고성능 샘플 기준). 화법은 [규칙] 판정이지만 실무상 대부분 이 풀에서 뽑으므로 고정 재료로 함께 수록. 스왑 규칙은 §4 참조.

**🔴 CP 화법**
```
"고객님 상황을 종합적으로 분석한 결과 가장 적합한 준비는 이 방향입니다."
"제가 고객님이라면 이 방향으로 준비하겠습니다."
"보험은 가입보다 관리가 더 중요합니다. 끝까지 함께하겠습니다."
"고객님께 가장 도움이 되는 기준으로 안내드리겠습니다."
"지금 준비하시는 것이 가장 안정적인 선택이라고 생각합니다."
```

**🟠 NP 화법**
```
"고객님 말씀을 들어보니 어떤 부분이 가장 고민되시는지 충분히 이해했습니다."
"그 마음이라면 누구라도 같은 고민을 하셨을 것입니다."
"고객님께 가장 도움이 되는 방향으로 함께 준비해 보겠습니다."
"보험을 권하는 것이 아니라 고객님께 꼭 필요한 준비를 함께 도와드리는 것입니다."
"앞으로도 안심하실 수 있도록 끝까지 함께 관리해 드리겠습니다."
```

**🔵 A 화법**
```
"고객님께 이 보장을 권하는 이유는 세 가지입니다."
"현재 가입하신 보험과 비교하면 가장 큰 차이는 이 부분입니다."
"보험료보다 중요한 것은 실제 보장을 얼마나 받을 수 있는가입니다."
"쉽게 비교해서 설명드리겠습니다."
"객관적으로 보면 고객님께는 이 방향이 가장 유리합니다."
```

**🟢 FC 화법**
```
"고객님께 꼭 필요한 내용만 이해하기 쉽게 설명드리겠습니다."
"어려운 보험용어는 쉽게 풀어서 안내드리겠습니다."
"고객님 상황에 맞는 내용을 차근차근 설명드리겠습니다."
"궁금한 점은 언제든 편하게 질문해 주세요."
"오늘 상담이 고객님의 미래를 준비하는 좋은 시간이 되었으면 좋겠습니다."
```

**🟣 AC 화법**
```
"고객님께 부담을 드리기 위한 상담이 아니라 가장 좋은 준비를 함께 찾기 위한 상담입니다."
"고객님의 의견을 충분히 듣고 가장 적합한 방향을 함께 결정하겠습니다."
"궁금한 점은 작은 것이라도 편하게 말씀해 주세요."
"충분히 이해하신 후 결정하셔도 괜찮습니다."
"고객님께 가장 도움이 되는 방향을 끝까지 함께 안내드리겠습니다."
```

### 2-4. ③~⑦ 거절 대응 고정 라인 (블록 #11, 표준 버전)

**🔴 CP 거절 대응**
```
[유도] "고객님께서 가장 고민되시는 부분이 무엇인지 함께 확인해 보겠습니다."
[마무리] "고객님의 현재 상황을 고려하면 지금 준비하시는 것이 가장 좋은 선택이라고 생각합니다."
```
**🟠 NP 거절 대응**
```
[공감] "충분히 고민하시는 것이 맞습니다."
[유도] "가장 고민되시는 부분이 무엇인지 말씀해 주시면 함께 해결방법을 찾아보겠습니다."
[안내] "고객님께 도움이 될 수 있는 부분이 있다면 조금 더 자세히 안내드리겠습니다."
[마무리] "고객님의 현재 상황을 함께 살펴본 결과 지금 준비하시는 것이 가장 좋은 선택이라고 생각합니다."
```
**🔵 A 거절 대응** (거의 완전 고정)
```
"충분히 비교해 보시는 것이 좋습니다. 다만 보험료뿐 아니라 보장 범위와 보험금 지급 기준까지 함께 비교해 보시면 더 정확한 판단이 되실 것입니다."
[마무리] "고객님의 현재 상황을 종합적으로 고려하면 지금 준비하시는 것이 가장 합리적인 선택이라고 생각합니다."
```
**🟢 FC 거절 대응**
```
"고객님, 가장 고민되시는 부분이 있으실까요?"
"제가 조금 더 설명드리면 결정하시는데 도움이 될까요?"
"고객님께 가장 적합한 방향을 함께 찾아드리겠습니다."
[마무리] "고객님 상황을 함께 살펴본 결과 지금 준비하시는 것이 앞으로 가장 도움이 되는 선택이라고 생각합니다."
```
**🟣 AC 거절 대응**
```
"고객님께서 가장 고민되시는 부분이 무엇인지 말씀해 주시면 함께 해결방법을 찾아보겠습니다."
"고객님께서 편안하게 결정하실 수 있도록 부족한 부분이 있다면 더 설명드리겠습니다."
[마무리] "고객님의 현재 상황을 충분히 고려하면 지금 준비하시는 것이 가장 안정적인 선택이라고 생각합니다."
```

### 2-5. ⑧ 거절 심화 도입부 (블록 #13)

```
보험영업에서 거절은 실패가 아니라 고객이 아직 결정을 내리지 못한 과정입니다. 고객이 "생각해 보겠습니다.", "가족과 상의해 보겠습니다.", "다음에 다시 연락드리겠습니다."라고 말하는 것은 대부분 {이름} {호칭}을 거절하는 것이 아니라 아직 확신이 부족하거나 결정할 준비가 되지 않았다는 의미입니다. 따라서 거절을 개인적인 실패로 받아들이기보다 고객이 무엇 때문에 망설이고 있는지를 확인하는 것이 훨씬 중요합니다.
```

### 2-6. ⑧ 거절 심화 질문/공감/방향 스톡 (블록 #15)

```
[질문 3종]
"고객님께서 가장 고민되시는 부분이 무엇이실까요?"
"보험료가 부담되시는 걸까요, 아니면 조금 더 생각할 시간이 필요하실까요?"
"제가 조금 더 설명드리면 결정하시는데 도움이 될 부분이 있을까요?"

[공감 3종]
"충분히 고민하시는 것이 맞습니다."
"그 부분은 많은 고객님들도 처음에는 같은 고민을 하셨습니다."
"신중하게 결정하시는 것이 당연합니다."

[방향 제시 3종]
"고객님의 현재 상황을 충분히 고려하면 지금 준비하시는 것이 가장 좋은 선택이라고 생각합니다."
"보험은 문제가 생긴 후 가입하는 상품이 아니라 준비할 수 있을 때 미리 준비하는 상품입니다."
"오늘 계약을 권하는 것이 목적이 아니라 고객님께 가장 좋은 준비 시기를 놓치지 않으셨으면 하는 마음입니다."
```

### 2-7. ⑨ 소개 도입부 (블록 #19)

```
소개는 부탁해서 만들어지는 것이 아니라 신뢰가 쌓여 자연스럽게 만들어지는 결과입니다. 고객은 보험상품을 소개하는 것이 아니라 '믿을 수 있는 {이름} {호칭}'을 소개합니다. 계약이 끝나는 순간이 영업의 끝이 아니라 고객관리의 시작입니다. 계약 이후 고객을 얼마나 꾸준히 관리하느냐에 따라 소개의 수와 고객의 평생가치는 크게 달라집니다.
```

### 2-8. ⑨ 소개 요청 멘트 3줄 (블록 #22)

```
"고객님, 혹시 주변에 보험 때문에 고민하시는 분이 계시면 편하게 소개만 부탁드립니다. 고객님께 상담드렸던 것처럼 정성을 다해 도와드리겠습니다."
"고객님처럼 보험의 중요성을 잘 이해하시는 분이 주변에도 계시면 같은 마음으로 도움을 드리고 싶습니다."
"고객님께 도움이 되었던 것처럼 소중한 분들께도 최선을 다해 상담드리겠습니다."
```

### 2-9. ⑨ 고객관리 체크리스트 ✔ 6줄 (블록 #23)

```
✔ 계약 후 3~7일 안부전화하기
✔ 보험금 지급 시 직접 축하와 안내 연락하기
✔ 생일과 기념일 축하 문자 보내기
✔ 계절이 바뀔 때 건강 안부 인사하기
✔ 1년에 한 번 보장분석 및 보험점검 상담하기
✔ 결혼, 출산, 자녀 입학 등 가족의 변화가 있을 때 먼저 연락하기
```
(변형: 2번을 "직접 진행 상황 안내하기", 6번에 "은퇴" 추가하는 샘플 존재. 표준은 위 버전.)

### 2-10. ⑨ 감사 멘트 2줄 (블록 #24)

```
"고객님, 소중한 분을 소개해 주셔서 진심으로 감사합니다. 고객님의 믿음에 보답할 수 있도록 최선을 다하겠습니다."
"소개해 주신 소중한 인연도 고객님을 상담했던 마음 그대로 정성껏 도와드리겠습니다."
```

## 3. [규칙] 매핑 — 저성향(0~10점) '의식적으로 ✔…' 행동 메뉴 5세트

지침 §6에서 확정된 저성향 코칭 세트. 리포트 어느 위치든 해당 트레잇이 0~10점이면 이 세트를 삽입한다.
왼쪽은 지침의 추상 메뉴(짧은 동사형), 오른쪽은 샘플에서 실제 실현된 멘트/문장(복붙 가능).

### CP 낮음 (지침 메뉴)
```
✔ 결론 먼저 말하기
✔ 방향 제시하기
✔ 선택기준 제시하기
✔ 마지막에는 반드시 추천하기
```
실현 멘트(이서연 §2):
```
"지금까지 상담한 내용을 종합해 보면 고객님께는 이 방향이 가장 적합합니다."
"제가 고객님이라면 이 상품으로 준비하겠습니다."
"오늘은 고객님께 가장 좋은 선택을 자신 있게 권해드리고 싶습니다."
```

### NP 낮음 (지침 메뉴)
```
✔ 공감 먼저 하기
✔ 고객 감정 인정하기
✔ 고객 말을 끝까지 듣기
✔ "충분히 이해합니다." 사용하기
```
실현 멘트(이선규 §2/§4):
```
"그 부분이 가장 걱정되셨군요."
"충분히 그렇게 생각하실 수 있습니다."
"그 마음 이해됩니다."
(순서 습관: ① 고객의 말을 끝까지 듣는다 → ② 감정을 먼저 인정한다 → ③ 해결방법을 설명한다)
```

### A 낮음 (지침 메뉴)
```
✔ 이유 설명하기
✔ 비교 설명하기
✔ 숫자 활용하기
✔ 근거 설명하기
```
실현 4단계(이영수 §5, 이서연 §2):
```
① 이유: "고객님께 이 보장을 추천드리는 이유는 세 가지입니다."
② 비교: "현재 가입하신 보험과 비교하면 가장 큰 차이는 이 부분입니다."
③ 근거/숫자: "예를 들어 같은 보험료라도 보장금액은 이렇게 차이가 납니다."
④ 결론: "그래서 고객님께는 이 준비가 가장 적합합니다."
```

### FC 낮음 (지침 메뉴)
```
✔ 미소를 많이 짓기
✔ 고개 끄덕이기
✔ 리액션 크게 하기
✔ 밝은 목소리 사용
✔ 고객 이름 자주 불러주기
```
실현 세트(이영수 §2/§6):
```
✔ 미소 짓기
✔ 고객 이름 자주 불러드리기
✔ 고개 끄덕이며 경청하기
✔ 좋은 질문에는 긍정적인 리액션 보이기
✔ ("좋은 질문입니다.", "맞습니다.", "충분히 그럴 수 있습니다." 리액션 사용)
```

### AC 낮음 (지침 메뉴)
```
✔ 부담 여부 묻기
✔ 질문 유도하기
✔ 이해 여부 확인하기
✔ 결정을 재촉하지 않기
```
실현 멘트(김정임 §2, 이선규 §7, 이영수 §7, 허진랑 §2/§8):
```
"고객님, 혹시 제가 조금 빠르게 설명드린 부분은 없었을까요?"
"궁금하시거나 부담되시는 부분은 편하게 말씀해 주세요."
"고객님께서 충분히 이해하신 후 결정하셔도 괜찮습니다."
"제가 설명드린 내용 중 가장 궁금하신 부분은 무엇이실까요?"
"혹시 아직 결정하시기 어려운 이유가 있으실까요?"
"고객님께서 이해하신 내용을 함께 다시 한번 정리해 드리겠습니다."
```

### 화법 스왑 규칙 (블록 #10 보조)
- 기본은 §2-3의 유형별 화법 풀 5줄을 그대로 사용.
- **A가 낮으면** NP·CP·FC 화법의 한 줄을 `"추천드리는 이유를 쉽게(하나씩/차근차근) 설명드리겠습니다."`로 스왑(이유 강조).
- 예: NP 화법 4번 라인 "보험을 권하는 것이 아니라…" → 저A 사람은 "추천드리는 이유를 쉽게 설명드리겠습니다."로 교체(이선규·이영수 실측).

## 4. [생성] 슬롯 목록 — 산문 생성이 필요한 위치와 입력 규칙

각 슬롯은 LLM 생성이 필요하다. 괄호 안은 그 문단이 참조하는 입력(어느 점수를 고르는지).

| 슬롯 | 위치 | 입력(참조 점수) | 생성 규칙 |
|------|------|----------------|-----------|
| G1 | ② 강점 문단 | 상위 1~3개 점수 | 최고 점수를 "가장 높은 성향"으로 명명→강점 서술. 2~3위 점수를 보조 강점으로 연결 |
| G2 | ② 조율 문단 | 최저 점수(0~10). 복수면 모두 | 낮은 트레잇을 지목→그로 인한 상담 리스크 서술. 뒤에 [규칙]§3 저성향 세트 삽입 |
| G3 | ② 📌 핵심 코칭 | 최고+최저 점수 | "이미 가진 강점 + 더할 습관" 한 문단 |
| G4 | ③~⑦ 🌿 잘 맞는 부분 (×5 유형) | 그 고객유형과 궁합 좋은 상위 점수 2~3개 | 고객유형이 원하는 가치(CP=신뢰, NP=공감, A=논리, FC=분위기, AC=배려)에 PA의 상위 점수를 매칭해 시너지 서술. **핵심 생성 슬롯** |
| G5 | ③~⑦ 💼 마음가짐 기본 (×5) | 고객유형 | 유형별 취지는 고정이나 문장 재작성(느슨 템플릿). 표준화 시 [고정]으로 승격 가능 |
| G6 | ③~⑦ 📌 핵심 코칭 (×5) | 그 사람 강점 + 해당 유형 처방 | 개인 강점→"여기에 ○○를 더하라" 한 문단 |
| G7 | ⑧ 강·약점 진단 문단 | 최고+최저 점수 | 최고 강점이 거절 상황에 어떻게 작동/한계인지, 최저 트레잇 보완 필요를 서술 |
| G8 | ⑧ 📌 핵심 코칭 | 최고+최저 | 개인 처방 |
| G9 | ⑨ 강점 문단 | 관계형 상위 점수(NP·FC·A 등) | 상위 점수를 소개영업 자산으로 연결 |
| G10 | ⑨ 저성향 보완 문단 | 최저 점수(특히 AC·CP) | 소개 요청/선연락을 못 하게 만드는 저성향 지목→관점 전환 서술 |
| G11 | ⑨ 📌 핵심 코칭 | 최고+최저 | 개인 처방 |
| G12 | 🍀 마지막 클로버 멘트 | 최고 강점 1~2개 | "{이름} {호칭}의 [강점]에 [보완]이 더해지면 …성장" 비전 한 문장 |

### 생성 슬롯 공통 어휘 매핑 (참조용)
- CP 상위 → "명확한 방향 제시 / 결단력 / 리더십 / 기준 제시"
- NP 상위 → "공감 / 경청 / 배려 / 편안함"
- A 상위 → "객관적 분석 / 논리 / 근거 / 설명력"
- FC 상위 → "친화력 / 밝은 분위기 / 소통 / 편안한 대화"
- AC 상위 → "존중 / 조율 / 부담 없음" (단 AC 과잉(15+)은 소개·추천 망설임 리스크로 서술)
- 저성향 → §3 [규칙] 세트 그대로 삽입
