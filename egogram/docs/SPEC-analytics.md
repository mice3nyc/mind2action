# SPEC-analytics — 캠페인 분석 페이지 (강사 사전 준비용)

상태: v1 실험 빌드 (2026-06-16). 추가 모니터링 화면. 라이브 설문/리포트에 영향 없음.

## 목적

강사가 강의 전에 한 캠페인을 열어 "이 집단이 누구인가 + 무엇이 성과와 함께 가는가"를 30초에 잡고, 강의에서 바로 쓸 거리를 건진다. 개인 점수 나열(결과 탭)에서 집단 특성으로 한 단계 올라가는 화면.

- 사용자: 관리자(피터공/손소장). 인증 뒤.
- 단위: 캠페인 하나씩 (드롭다운 전환).
- 별도 작업: 강의장 라이브 제시용은 손소장 논의 후 분리 빌드.

## 접근

- `#/admin` → 탭 "캠페인 분석" (campaigns/dashboard/results 옆 4번째).
- 컴포넌트: `src/components/Admin/CampaignAnalytics.jsx`.
- 데이터: AdminDashboard가 가진 `results`(전체 응답) + `campaigns`를 props로 전달. 추가 fetch 없음.
- 응답 필터: `r.campaignId === selectedCampaignId`. 기본 선택 = 응답 수 최다 캠페인.

## 데이터 (storage.js loadResults 형태)

한 응답: `{ scores:{CP,NP,A,FC,AC}(0-20), total, top1, top2, bottom, grades, careerMonths(int), jobType, incomeRange, recruitCount(text), department, company, name }`.

집계 헬퍼:
- `parseRecruit(text)`: 문자열에서 숫자 추출(`"3명"→3`), 없으면 null.
- 소득 순서: under200 < 200-400 < ... < over2000.
- 경력 구간: 신입(≤12) / 중견(13-36) / 베테랑(>36).
- 직무 역할: roleFromJobType (sales / manager / coach).
- 채움률: 각 메타 필드 비어있지 않은 비율. 성과 교차는 채움 응답만 대상, 너무 적으면 경고/숨김.

## 6구획

1. **헤드라인** — 자동 생성 한 문장("N명, 평균적으로 {가장 강한 축}이 강하고 {가장 약한 축}이 약한 집단") + 핵심 숫자 카드(인원·평균 총점·최강 축·최약 축).
2. **집단 자아상태** — 5축 평균 레이더(SVG 펜타곤, grid 5/10/15/20) + 축별 분포 스트립(0-20 트랙에 개인 점 흩뿌림 + 평균 마커). 평균 모양 + 평균 뒤 다양성.
3. **유형 지도** — top1 분포 막대(축 색), 강점 조합(top1+top2) 상위, 이 집단에 없는 top1 유형 칩.
4. **공통 약점** — bottom 분포 막대 + 최다 약점 한 줄 처방 문장.
5. **성과의 결** — 직무 역할별 5축 평균 대조 + 리크루팅/소득 상위군 대 하위군 5축 대조 + 경력 구간별. 각 그룹 N 표시. 표본 작으면(<5) 주의 마크. 메타 채움률 낮으면 해당 축 숨김.
6. **발견 카드** — 가장 균형잡힌 사람(5축 표준편차 최소)/가장 극단적인 사람(최대)/희귀 조합(1명뿐인 top1+top2). 강의에서 쓸 거리.
